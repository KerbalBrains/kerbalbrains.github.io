BADGE BAR

See your mods at a glance on the main menu.

What it does

Badges for the mods you have

Start KSP and look at the bottom-left corner of the main menu. Under the Kerbal Brains Mods badges, a YOUR MODS row counts every mod you have and shows a badge for each popular mod it finds.

Make your own

Add a badge for another mod

  1. Open the popular folder inside GameData/BadgeBar/PluginData.
  2. Add a round picture, 256 × 256 with see-through corners, named for the mod, like tundra.png.
  3. Add a text file with the same name, tundra.cfg:
name = Tundra Exploration
detect = TundraExploration    // the mod's folder name in GameData
order = 130                   // bigger number = later in the row

Restart KSP. If the mod's folder is in GameData, the badge shows up. Use a star at the end to match many folders, like NearFuture*.

Troubleshooting

Something not right?

A mod I have doesn't get a badge

Only the 12 mods above have badges. Add your own with the steps above.

The number of mods looks high

It counts every folder in GameData except the game's own (Squad). Some mods use more than one folder, like helper libraries.

I don't see the badge panel at all

Check that GameData/BadgeBar/Plugins/BadgeBar.dll exists, then restart KSP. The panel only shows on the main menu.

How do I remove it?

Delete GameData/BadgeBar. Our other mods' badges still show without it.
